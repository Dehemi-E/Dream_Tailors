# Dream Tailors

Dream Tailors is a web-based Tailor Shop Management System developed using Laravel and MySQL.

## About the Project

The system is designed to digitalize and simplify the daily management activities of a tailor shop. It reduces manual paperwork and helps manage customers, measurements, orders, payments, and invoices efficiently.

## Main Features

### Admin
- Customer Management
- Order Management
- Measurement Management
- Offline Payment Management
- Invoice Generation
- Order Status Management
- Dashboard

### Customer
- Customer Registration and Login
- View Order Details
- View Order Status
- View and Update Measurements
- View Invoice
